# 🚀 Guia Rápido - Gerador de Posts Instagram

> **5 minutos para começar a criar posts profissionais!**

---

## ⚡ Início Rápido

### 1️⃣ Configuração Inicial (Uma vez apenas)

```bash
# 1. Copie o arquivo de exemplo
copy .env.example .env

# 2. Abra .env e adicione suas chaves:
# OPENAI_API_KEY=sk-sua_chave_aqui
# REPLICATE_API_TOKEN=r8_sua_chave_aqui

# 3. Execute o aplicativo
run_instagram_generator.bat
```

### 2️⃣ Onde Obter as Chaves de API

**OpenAI (GPT-4)**
- 🔗 https://platform.openai.com/api-keys
- 💰 Custo: ~$0.03 por post

**Replicate (Flux.1)**
- 🔗 https://replicate.com/account/api-tokens
- 💰 Custo: ~$0.04 por imagem

## 📸 Criar Post Normal (3 passos)

1. **Aba**: "📸 Posts Normais"
2. **Preencher**:
   - Tipo: Feed / Reel / Stories
   - Nicho: "Fitness"
   - Tema: "5 dicas para treino matinal"
   - Tom: Profissional
   - CTA: Comentar
3. **Clicar**: "🚀 GERAR POST PROFISSIONAL"

⏱️ **Aguarde 2-3 minutos** → Pronto!

---

## 🌅 Criar Bom Dia Motivacional (2 passos)

1. **Aba**: "🌅 Bom Dia Motivacional"
2. **Escolher**:
   - Categoria: "Sucesso"
   - Subtema: (opcional) "Segunda-feira"
3. **Clicar**: "🌅 GERAR BOM DIA MOTIVACIONAL"

⏱️ **Aguarde 2-3 minutos** → Pronto!

---

## 💾 Salvar Resultados

Após geração bem-sucedida:

| Botão | Ação |
|-------|------|
| **💾 Salvar Tudo** | Salva imagem + texto em arquivo |
| **🖼️ Salvar Imagem** | Salva só a imagem PNG |
| **📋 Copiar Texto** | Copia legenda + hashtags |

## 🆘 Problemas Comuns

### ❌ "Chave da API não encontrada"
→ Configure o arquivo `.env` com suas chaves

### ❌ "Erro ao conectar"
→ Verifique internet e validade das chaves

### ⏳ "Está demorando muito"
→ Normal! Geração de imagem pode levar 2-3 minutos

### 🖼️ "Imagem não aparece"
→ Aguarde a mensagem de sucesso

## 💡 Dicas Profissionais

1. **Seja específico no tema** - "10 exercícios para glúteos" é melhor que "exercícios"
2. **Varie o tom** - Teste diferentes tons para ver o que funciona
3. **Revise hashtags** - Você pode editar antes de publicar
4. **Salve sempre** - Mantenha backup de tudo que gerar
5. **Teste subtemas** - No Bom Dia, subtemas dão mais personalização
